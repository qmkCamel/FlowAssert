# AppClaw attribution

The distributed JavaScript bundles selected modules from `@appclaw/core@2.7.0` (upstream commit `9bbc6f198b9ecf81400d96977bea9a9946af360e`), maintained by AppClaw contributors at https://github.com/appclawhq/AppClaw.

The upstream Apache License 2.0 text is retained in `AppClaw-LICENSE.txt`, obtained from that exact commit. Bundling changes module packaging; the upstream executor is not patched. Mobile Mirror supplies its own restricted device facade and worker lifecycle. Other external dependencies retain their own package licenses.
