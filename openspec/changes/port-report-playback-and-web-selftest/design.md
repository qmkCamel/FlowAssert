## Context

个人版 dev 工作区已有未提交的模拟器连接变更。先备份原始文件，再按能力对独立维护分支增量进行三方合并；冲突逐项处理。仅使用文件级补丁，不合并另一仓库历史。

## Decisions

1. 回放复用登记证据、读租约、哈希与有限图片预算；不连接设备、不重跑历史。
2. 动作前截图与真实坐标属于新增运行证据；动作后展示本步终态。辅助截图失败如实标注，不能拼造旧报告材料。保留取消及未知派发状态约束。
3. Web 自检默认关闭，使用独立合成目标、固定场景及工具链。采集、图像复核和独立验证分别存储；没有复核不得判视觉通过。
4. 文档与生成器改用个人仓库地址和 dev 阅读入口，包内链接通过实际 pack 清单校验；可选 CI 采用 workflow_dispatch、自托管专用 runner 和显式选择。
5. 不复制源仓库 artifacts、忽略目录、公司协作/发布配置和历史验收原件。说明性 SVG 经审阅后可迁入；运行截图由目标仓库隔离 Mock 验证重新生成并查看。
6. 保留原有个人版 GitHub 治理与历史扫描边界，不通过扫描豁免掩盖既有问题。

## Validation

运行 pnpm check、pnpm test:e2e、pnpm build、pnpm pack:check、严格 OpenSpec 和 diff 检查。检查运行截图，并对新增/变更文本扫描内部域名、组织身份、绝对个人路径和凭据。按实际环境运行可选 Web 编译链探针；真机时延、远程 CI、人工像素基线没有实测时保持未验。
