## ADDED Requirements

### Requirement: 通用能力迁移保持个人版边界
系统 SHALL 在个人版中提供报告回放、动作取证和默认关闭的 Web 自检，保留已有模拟器连接及个人仓库工程治理，不依赖组织内部服务或私有材料。

#### Scenario: 无内部环境的开发机使用回放
- **WHEN** 用户读取个人版已登记的完成运行
- **THEN** 可播放截图并定位失败，不访问组织服务、不控制设备，缺失证据明确提示

#### Scenario: 未启用可选 Web 能力
- **WHEN** Viewer 未显式启用 Web 自检
- **THEN** 不显示 Web 创作入口，原生设备与模拟器功能继续可用

### Requirement: 迁移证据不得混同来源验证
交付记录 SHALL 区分目标仓库重跑结果、历史来源说明及未验证边界。迁入文件 SHALL 不包含组织内部地址、身份或私有运行材料。

#### Scenario: 浏览器验证完成
- **WHEN** 目标仓库在隔离 Mock 环境完成回归
- **THEN** 记录该轮结果并检查运行截图，不据此宣称真机、远程 CI 或人工视觉基线通过
