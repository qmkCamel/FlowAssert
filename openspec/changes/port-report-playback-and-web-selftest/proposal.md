# 回迁报告回放、视觉自检与文档维护能力

## Why

个人版已具备本机设备、用例与报告基础，需要吸收独立维护分支的通用报告回放、动作取证、Web 视觉自检和文档维护增量。迁移必须保留当前未提交的模拟器支持，避免引入组织专属配置、业务材料和内部身份。

## What Changes

- 引入截图播放、时间线、语义步骤、失败定位、动作前后与已记录坐标展示，并带入慢图竞态及布局稳定性修复。
- 引入默认关闭的 Web 用例、隔离自检执行、取消/重试/重启恢复、视觉复核、独立检查及像素基线工具。
- 引入文档链接、任务计数与分发完整性检查，以及 FAQ、术语、维护指南和可离线阅读的通用技术介绍。
- 引入离线演示的本机历史截图加载与显式导出功能；内置业务用例替换为通用 Mock 示例，不携带源侧材料。
- 将可选视觉取证 CI 适配为个人仓库的 GitHub 手动工作流，保留现有发布及权限模型。
- 仅迁移通用代码、测试和规格；不导入内部仓库地址、组织身份、私有截图/日志/运行目录或源分支 Git 历史。

## Impact

- 报告、工作台执行、存储、Viewer 与工程门禁。
- 当前模拟器实现原地保留；不引入第二套连接模型或历史兼容层。
- 历史结果不能冒充本次验收；Mock、浏览器、自检和真机验证分别记录。
