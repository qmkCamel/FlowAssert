## Context
当前浏览器 MediaRecorder 复用 PNG/MJPEG/WebCodecs 画面。工作台 manifest 由 worker 事件连续更新，不能让异步视频写入覆盖它。
## Goals / Non-Goals
显式选择后自动录制并归档，重启回放和步骤跳转。非目标：设备原生录像、后台持续录制、声音、远端同步、崩溃无损视频。
## Decisions
- 保留手动按钮；工作台录制独占同一录制器，开始前检查有效画面及格式。不支持或已有手动录制时给出错误，用户可取消勾选继续无录像测试。
- 在 POST run 前开始录制；请求携带随机 captureId、sessionId 和浏览器开始时间。服务器校验会话、时间与字段。录制与绑定失败则不继续归档到其他 run。
- 后台独立轮询自己绑定的 run，不依赖工作台是否展开、选中了哪条历史；收到终态后自动停止。用户停止/页面隐藏/换会话/上限/编码错误属于部分录像。
- 完整 Blob 在结束后上传，同源、固定 MIME/文件名、136 MiB 请求上限（含末尾分片余量）、单上传互斥及读取超时。成功写不可变 recording.webm/mp4 并计算 hash；独立 video.json 原子提交，避免 worker manifest 竞态。重试同一内容幂等，拒绝不同内容覆盖。
- run 的初始 video 元数据持久化；视频状态独立于断言 verdict。视频 sidecar 或内容损坏不得变成成功回放；重启后未提交录像显示中断，原必需证据语义不变。浏览器强制关闭可能丢失未上传 Blob，明确不保证崩溃录像恢复。
- 视频读取验证哈希后支持单区间 Range；浏览器历史播放器、下载及步骤按钮只访问本机证据路由。旧 run 无视频正常显示。
- 步骤位置按服务器步骤 startedAt 与同机浏览器 recording startedAt 对齐，标记为近似时间（有媒体延迟和采集误差），不伪称逐帧原子同步；超出录制范围的步骤不允许跳转。
- 现有 10 分钟/128 MiB、无声音限制不变。上传等待显示进度，其他控件可操作；失败保留本页下载和重试。
## Risks / Trade-offs
最终上传需要页面存活；文件在页面消失前未保存会明确缺失。视频是辅助证据，测试通过与录像成功分别显示。服务器不新增 ffmpeg 依赖，校验 MIME/文件头和 hash，不把此校验称为完整解码；可播放性由浏览器 E2E 验证。
## Migration Plan
新增可选字段兼容旧 schemaVersion 1；独立 sidecar 不改变原 manifest 保存时序。回滚前端/路由后原 YAML/PNG/XML 仍可读。
