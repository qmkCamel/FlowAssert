## 决策

采用 `artifacts/curated/` 表达经过挑选、可进入提交审查的材料，采用 `artifacts/local/` 保存全部新生成产物。Git 默认忽略 artifacts 下其他根项，仅放行 curated 和 README；目录门禁发现旧生成器重新创建的路径即失败，而不是静默忽略。

自动化只写 local，人工检查并复制少量材料到 curated。媒体继续使用既有 `public-media-review.json` 的内容哈希与审查说明；迁移不刷新图片字节或冒充重新验收。历史日志和 JSON 内嵌路径作为原始记录保留，Markdown 导航和当前工具路径更新。

已跟踪的 207 个文件只做目录归属迁移；其中旧日志和真机图片维持既有历史地位，不为新增原始材料提供例外。未跟踪排障文件只移动，不修改、不提交。

## 验证

目录门禁通过临时 Git 仓库验证默认忽略、精选材料可跟踪、强制加入 local 被拒绝及旧目录被发现。检查媒体哈希、文档链接、自动生成文档、CI 产物路径与安装包边界。执行全部项目门禁和 public readiness、严格 OpenSpec 检查；E2E 后再次检查目录，证明生成器未创建旧路径。Viewer 实现无改动。
