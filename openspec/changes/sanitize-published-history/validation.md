现有工作区已采用新克隆的 Git 元数据；原 Git 数据、原跟踪文件和关联 worktree 移至受限本地备份，旧副本均设有阻止推送的 hook。当前工作区保留原有忽略文件，已知私有真机材料继续被忽略。仓库维持 Private，现有 release 资产未改动。

远端旧版主分支 CI 的一项时间戳断言出现 1 毫秒偏差而失败；这是旧版分支运行结果，不能用本地开发分支的通过结果替代。开发分支完整本地验证结果见上表，远端 CI 单独核实。

标签更新触发了该旧标签版本的发布工作流，在创建同名既有 Release 时退出；三个既有资产的 ID、更新时间和摘要未改变，没有重新发布安装包。

缓存状态：重写与 Actions 删除后，认证 API 仍能访问原敏感提交及图片对象。支持中心停在登录页，清理申请已准备在受限本地目录，尚未提交；本变更任务完成只表示仓库引用清洗和边界记录完成，不表示平台缓存已删除。

GitHub 缓存和旧对象的物理回收是独立外部步骤。更新 Git 引用或删除 Actions 记录不等同于已经完成平台缓存删除，也不能撤回他人已保存的克隆。
