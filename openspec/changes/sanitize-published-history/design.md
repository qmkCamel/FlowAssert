# 设计

使用 git-filter-repo 对全部远端分支及标签执行同一组规则。文本替换避开图片 Base64；归档内文本发生变化时同时更新 Base64、字节数和 SHA256，保留原始证据与脱敏示例的语义边界。已泄漏图片从所有历史删除。旧提交标识不再作为文档导航。

隐私检查不再按 legacy boundary 豁免作者邮箱，扩展至提交说明、标签身份、所有文本文件和已知私有图片指纹。使用包含旧邮箱、日志和复合扩展名的临时仓库回归，确认配置不能绕过检查。

更新远端前核对原分支 SHA，使用带期望旧值的 lease 和原子推送，避免覆盖任务期间的新提交。推送后从远端重新克隆并扫描。现有工作区先备份 Git 元数据和旧跟踪文件，再切换到清洗后的元数据；忽略的本地材料不外传。
