## ADDED Requirements

### Requirement: 小范围内测必须具有可复现入口
内测材料 SHALL 指定 dev 分支源码入口、提交 SHA 记录方法、冻结锁文件安装、工具链、更新方法、最小体验任务和退出方法。内测 MUST NOT 要求独立候选包作为前置条件。材料 MUST 区分分支内测、正式发布、作者验证和非作者体验。

#### Scenario: 首次使用者完成固定体验
- **WHEN** 使用者从内测入口开始
- **THEN** 可以按步骤完成 Mock 正例、故意失败、复验和报告分享
- **AND** 可以提交脱敏的耗时、错误码与求助记录
- **AND** 未执行的独立研究和发布门禁保持未完成

### Requirement: 宣传演示必须自包含且保持模拟边界
默认演示 SHALL 在单文件离线场景可用，无需私人媒体、设备或模型。复验 MUST 创建独立模拟记录并保留旧失败，导出 MUST 显著标记模拟且不宣称真实产品验证。原始本机真机材料 MUST 由用户显式选择后加载。

#### Scenario: 离线读者从失败进入复验
- **WHEN** 读者运行失败案例并选择修正期望后复验
- **THEN** 可以分别阅读原失败与新通过记录
- **AND** 下载内容与已审查的模拟报告预览一致
- **AND** 不连接设备、不发送数据、不加载私人素材
