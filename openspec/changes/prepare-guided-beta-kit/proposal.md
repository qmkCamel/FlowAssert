# 补齐小范围内测材料

## Why

固定 UI 流程与报告已有工程及有限真机证据，但初次体验仍分散，宣传稿混合历史补记，HTML 默认依赖不分发的私人真机材料。需要一个可复现、可反馈的内测入口。

## What Changes

- 提供 dev 分支源码任务卡、提交 SHA 与锁文件说明、更新/退出方法及非作者体验记录模板；按用户确认不维护独立内测包。
- 重写宣传正文，更新单文件离线 Mock 演示：失败定位、新运行复验、保留旧失败、预览并下载模拟报告。
- 真机历史回放保留在显式选择的本机入口，不默认加载私人素材。
- 更新中英文入口及反馈模板，保留原有真实业务、设备矩阵和发布门禁缺口。

## Impact

只变更文档、宣传演示及其验证材料，不修改设备控制、业务执行器或权限。分支内测不等于正式发布，不改写 Git 历史、不豁免 public readiness。用户研究待真实参与者完成。早先本机候选包验证仅保留为历史，不再作为用户入口。
