# 报告阅读与离线分享

本地 Viewer 的「运行记录」提供「全部运行 / 用例历史 / 趋势」。高级工作台保留原入口；既有分析 URL 的 summary、steps、evidence、details、compare、triage、share 都可使用。运行列表计算的是执行次数，趋势计算计划套件/用例分母，两者不能混用。

## 找到报告与定位失败

按结果、平台、来源、日期、名称/设备/用例 ID 和构建筛选。日期按本机时区解释，开始包含、结束为所选当天的次日零点（不包含）。每页 50 条，最多 10,000 条摘要。每份 manifest 上限 8 MiB、最多 4 个并发读取；超限作为不可读记录保留。现有 manifest 的内嵌 YAML 只随有界 JSON 解码，不进入摘要；不会打开独立 YAML 附件。统计覆盖整个筛选结果，而非仅当前页；不可读记录和未知构建显式显示。目录只检查登记元数据，不读取图片/录像/结构附件，也不把这次读取当作证据复验。分页绑定查询和摘要 generation，源记录变化时需要刷新。

用例历史要求明确 caseId；同名运行不会自动合并。修订、输入摘要、套件用例身份和重试序号在身份展开区查看。无关联的旧运行保留独立记录。

分析页默认选择首个记录失败，提供上/下一个失败和步骤搜索。搜索只控制列表展示，不改变失败计数；选中的步骤保持可达。只有运行级门禁失败时不编造失败步骤，展开「完整验证范围」查看必需项、未执行/未支持原因和测量阈值。原记录结果、当前材料可用性、派生来源结果分别显示。材料完整性校验通过不表示测试再次执行。

截图使用登记历史材料，支持适应、缩放和原尺寸；读取新步骤时保留旧图及旧图步骤身份。XML 和录像按需读取，录像定位是近似时间。缺图/坏 hash 显示错误，不用实时画面补充。比较必须显式选择基线，检查可比性；差异事实、分诊建议、人工复核与关联子运行复验分别阅读，复验通过不是根因证明。

## 截图序列回放

已结束运行的「步骤与证据」页提供「截图序列回放」。点击播放后从当前步骤按记录顺序展示截图，支持暂停、上一步/下一步、0.5× / 1× / 2×。默认 1× 每张停留 1.5 秒，加载时间另算；这是阅读节奏，不代表原执行耗时。没有录像也能回放，不需连接手机。

播放中的加载状态、动作字幕和重试按钮使用稳定占位，避免切步时画布上下跳动。超长字幕和状态可以在对应区域滚动读取，也支持键盘聚焦；新截图解码完成前保留带原步骤身份的上一张画面。主动展开动作对照、调整窗口或缩放图片仍会按用户操作改变布局。

抵达失败步骤会暂停，点击「继续」才向后播放。缺图、校验或解码失败会暂停并保留有原步骤标签的上一张可用图；可以「重试截图」或手动切换步骤，重试成功也不会自动播放。末尾显示「回放结束」，需显式从头播放；单步骤仅静态浏览。播放开始清空步骤筛选，手动选步、再次搜索、切页面/运行、浏览器后退或切到后台都会暂停。

截图回放与已有录像互斥播放；两者都不同于「按原快照复跑（新运行）」。回放不执行设备操作、不修改判定、不上传、不生成录像。离线 HTML 分享包仍是无脚本阅读文档，不包含此播放器。

### 回放工作台

「步骤与证据」首屏以历史画面和播放按钮为中心。顶部保留结果与证据限制，运行信息、完整验证范围及复跑入口收在「运行信息与操作」；右侧/下方「步骤详情」可查看预期、实际、源 YAML 和结构。步骤标题显示记录的目标与真实耗时，等待步骤可折叠；没有阶段名称时只按源流程分组，不推测业务含义。

使用「步骤时间线」拖动或键盘定位；手动选择会暂停。失败标记直接跳转对应步骤，计数不受搜索或折叠影响。「缩略图时间线」展开后按需读取当前附近最多五张图，切换窗口取消旧请求；它是步骤导航，不代表连续录屏时间。

新的本机坐标动作会有界保存动作前截图、实际点击/滑动坐标、图像几何与派发状态，并关联本步执行后截图。展开「动作前后对照与位置」会暂停回放；标记只画在本动作绑定的执行前图上。结果未知不等于点击成功，取证失败不补画标记。输入值不作为动作字幕保存；最多记录本步八个坐标动作，额外取证只在已有授权运行中进行。

旧记录或没有位置证据的步骤会显示「未记录」，不会使用上一张图、实时画面或推测坐标补齐。坐标系/尺寸不匹配时也不绘制标记。上述动作原始材料仍是本机私有证据，分享继续走原有逐项审查流程，不自动导出新的动作元数据。

## 遮蔽与导出

新分析页默认 HTML；高级工作台默认原 JSON。材料默认不选，HTML 可导出无附件阅读版，JSON 仍需选择 1–64 项登记材料。可按失败步骤快捷选择；图片和结构依旧需要人工审查。导出不自动上传，不生成公开托管链接。本地分析地址只在本机有效。

打开图片画框，选中遮罩可拖动或用方向键移动（Shift 加速），Delete 删除；「添加遮罩」、坐标数字输入、删除、撤销也可完全用键盘操作。高级坐标格式为源像素 `x,y,width,height;...`。缩放和 DPR 不改变存储单位；画框向外取整并限制在图像边界，每图最多 64 个矩形。黑色遮罩写入派生像素，原件保持不变；未遮蔽的像素仍可见。

点击预览后审查完整最终文件与省略范围，再勾选确认并下载。预览冻结标识、时间、格式、模板与实际字节；遮罩、选择或格式改变会清除确认，源 manifest 变化会拒绝导出。确认最多有效十分钟，重启后需重新预览。操作期间显示局部进度、可取消，其他导航仍可使用；转换失败保留上一预览，旧预览不代表新输入。进入提交阶段后取消不能撤销已提交文件。

HTML 可离线双击阅读：内嵌 PNG、原生锚点/details 和打印样式，无脚本、外链、网络请求、表单或服务依赖。文字仅保留白名单动作类型模板、状态与验证维度；完整私有断言、原始观察/错误、定位条件、运行名称、原始时间、设备/会话标识、日志、YAML、参数、录像和私有日志均省略。精确预期/实际可能因此不足，报告会明确说明。测量只保留无私有标识的数值和状态；健康未支持限制不会变成通过。

接收者会看到来源记录结果和「派生，未重新验证」。打开、打印或校验文件不证明真实来源、模型理解、真机业务通过或独立验收。HTML 是阅读文档，不是可导入/可复跑的归档。机器交换继续使用 JSON v2 或带 runtime 必需功能的 v4，未知必需功能不能降级为旧版通过。

## 契约、预算与回滚

- `GET /api/workbench/reports` 返回 contractVersion 1，独立于旧运行 API。严格拒绝未知/重复查询字段；日期、caseId、分页 cursor 有 schema 边界。cursor 必须匹配完整查询和摘要 generation。
- HTML jobs 请求使用 `format: "html", contractVersion: 1`；旧无 format 请求和旧 preview/export 端点保持 JSON 返回形状。
- ReviewedReportSnapshot v1 / template v1 是被动渲染器唯一输入，不传源 TestRun、任意路径或文件访问能力。
- 64 项附件，每项 4 MiB、合计 16 MiB、PNG 最大 4096×4096；文本字段最多 8 KiB，合计 256 KiB，500 步，64 项测量，序列化 HTML 最多 24 MiB。超限失败，不静默删材料；XML 角色文本还受 8 KiB 展示字段预算。
- 复用 store owner、读取 lease、来源映射/引用、磁盘 reservation、一个 active/两个 waiting 的队列和 30s 等待/转换期限。成功读取要求完整提交 manifest 与 archive/map/HTML hash 全部匹配。预览内存至多保留两份有效审查；新增预览可能替换最旧授权。
- 原 JSON提交 manifest v1 保留；带 HTML 的提交 manifest v2 增加 HTML hash。回滚到变更前 dev 可继续读取原 JSON与源运行，但不会提供新 HTML job下载，确认 token 也失效。先将需要的 HTML 文件下载到独立位置，再回滚，保留源映射与引用；不要手工移除私有 shares/job账本。详细实际包验证见 change 中 implementation-validation。

## 验收界限

软件 fixture 和 Mock 验证页面、契约、遮罩与包互操作。真实 Android/iPhone 归档、真实健康信号与五名非作者的任务研究分别验收，未完成前不以工程门禁替代。性能测量单独运行：`REPORT_PERFORMANCE=1 pnpm exec playwright test tests/e2e/report-reading.spec.ts -g '1000-summary' --workers=1`。冷样本定义为新页面导航，未驱逐文件系统缓存；同时记录受其他门禁负载干扰的结果。
