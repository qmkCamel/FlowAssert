# FlowAssert 0.1.0-alpha.1

> 历史发布说明：记录迁移前的版本，保留为背景材料；不是 FlowAssert 已发布或已验收安装包的声明。

首个可安装 GitHub prerelease。它提供只读 onboarding CLI、脱敏 doctor、安全配置生成、可选的 managed Appium 生命周期，以及从同一 tarball 验证的 DSH/MCP runtime。package 仍保持 `private: true`，本版本不发布公共 npm。

## 支持矩阵

| 层 | 本版本边界 |
| --- | --- |
| Node | `^22.19.0` 或 `>=24.0.0`；release runner 使用 24.19.0 |
| DeepSeek Harness | 精确 `@deepseek-ai/dsh@0.1.0-rc.8` clean profile |
| MCP/Codex | stdio MCP、八项工具、离散 PNG/结构；Codex 是已验证宿主之一，不是核心依赖 |
| Appium | external 默认；managed 显式 opt-in，release runner 固定 Appium 3.2.0 |
| Android | UiAutomator2；可选显式 scrcpy 4.1 H.264 Viewer 媒体 |
| iOS | XCUITest/WDA；可选 WDA MJPEG Viewer 媒体 |

已有单台 Android 14 与单台 iOS 26 的真机观察/动作/媒体证据，但 GitHub release runner 没有物理设备；clean-runner managed Appium smoke 只证明 server ready/stop/listener cleanup，不提升真机覆盖。

## 安装与升级

DeepSeek Harness rc.8：

```bash
dsh plugin --profile web add ./flowassert-0.1.0-alpha.1.tgz
dsh --profile web --dump-config
```

独立 CLI：

```bash
npm install --ignore-scripts --legacy-peer-deps --omit=dev \
  --prefix "$PWD/.mobile-mirror-alpha1" \
  "$PWD/flowassert-0.1.0-alpha.1.tgz"
node "$PWD/.mobile-mirror-alpha1/node_modules/flowassert/scripts/mobile-mirror-cli.mjs" --help
```

从仓库内构建的旧 `0.1.0` tarball 升级时，不要覆盖个人配置；先生成新模板并 diff，再把宿主指向新的 alpha.1 package path。完整命令见 [Beta 安装与回滚指南](../beta-installation.md)。

## Onboarding、MCP 与 Codex

```bash
node /ABSOLUTE/PACKAGE/PATH/scripts/mobile-mirror-cli.mjs doctor --platform all
node /ABSOLUTE/PACKAGE/PATH/scripts/mobile-mirror-cli.mjs \
  config --target mcp --platform mock > /ABSOLUTE/CONFIG/PATH/mobile-mirror.mcp.json
node /ABSOLUTE/PACKAGE/PATH/scripts/mobile-mirror-cli.mjs \
  config --target codex \
  --package-root /ABSOLUTE/PACKAGE/PATH \
  --config-path /ABSOLUTE/CONFIG/PATH/mobile-mirror.mcp.json
```

CLI 不直接修改 DSH/Codex 配置，也不向 agent 注册 doctor 工具。MCP 连续视频仍只存在于 loopback Viewer，不进入工具结果。

## Managed Appium

external 模式保持默认并从不终止外部 Appium。managed 模式要求用户显式设置绝对 `appiumExecutablePath` 和 loopback `appiumUrl`；Appium 只在真实 Appium start 时惰性启动。它拒绝 attached session 和已有 listener，等待 `/status` ready，正常退出时只清理本 runtime 保存的 child handle。

## 已知限制

- developer preview，不承诺后续 DSH preview、Appium driver 或 scrcpy 版本无迁移升级。
- doctor 只读且不自动修复 WDA 签名、设备信任、Developer Mode 或 Android 授权。
- managed runtime 正常退出可精确清理；进程被强杀仍可能留下 Appium 下游 orphan，当前不做跨进程扫描。
- 更广 Android OEM/iOS/Xcode/Apple 账号、多设备、旋转、断线恢复和可访问性矩阵尚未完成。
- 公共 DeepSeek V4 路由仍是 text-only；视觉验收需要实际支持 image input 的模型/provider。

## 回滚

先调用 `mobile_mirror_stop`，再移除 DSH plugin/Codex MCP 注册，并把宿主恢复到上一条已校验 package path。不要删除用户配置、attached session、系统 Appium/driver、证书或 WDA。详细边界见 [Beta 安装与回滚指南](../beta-installation.md)。
