# FlowAssert 0.1.0-alpha.2

> 历史发布说明：记录迁移前的版本，保留为背景材料；不是 FlowAssert 已发布或已验收安装包的声明。

> 历史候选说明，内容保留当时功能/宿主基线。2026-10-07 远端未发现对应 alpha.2 tag；本文不证明已发布，也不描述最新 dev。当前源码的 rc.2、Workbench/runtime 及报告分享见[能力表](https://github.com/qmkCamel/flowassert/blob/main/docs/capabilities.md)与[安装指南](../beta-installation.md)。

当时计划的第二版 GitHub prerelease 候选在 alpha.1 的 onboarding、managed Appium 与低延迟媒体基础上，增加 observation-bound 语义节点点击、受控普通文本输入和 owned-session 应用生命周期。package 继续保持 `private: true`，不会发布到公共 npm；DeepSeek Harness 验收基线固定为 `0.1.0-rc.8`。

## 新增能力

- `mobile_mirror_action` 从三种扩展为五种 canonical action：保留 `tap`/`swipe`/`back`，新增 `tap_node` 与 `input_text`。
- 新增第九工具 `mobile_mirror_manage_app`，支持受策略约束的 `activate`/`terminate`，结果不回显 app id。
- Android password 与 iOS secure text 节点在结构发布前标记 `sensitive` 并删除 name/text/value。
- 文本输入绑定 fresh observation、精确 node、focused active element 与 rect overlap；拒绝 locator、clipboard、shell 和隐式点击。
- 成功或可能已经发生 mutation 的失败都会递增 `screenEpoch`，迫使后续动作重新观察。
- DSH、MCP 和 Viewer 共用 generic control progress；慢操作期间保留最后画面和安全停止能力。

## 安全默认值

```json
{
  "agentScreenContentPolicy": "mock-only",
  "agentTextInputPolicy": "mock-only",
  "agentAppControlPolicy": "disabled",
  "agentAllowedAppIds": []
}
```

升级不会自动开启真机屏幕共享、文本输入或应用管理。`non-sensitive`、`session-app`/`allowlist` 都必须由用户在本地配置中显式设置；attached Appium session 永远不能执行应用生命周期 mutation。

## 支持矩阵

| 层 | 本版本边界 |
| --- | --- |
| Node | `^22.19.0` 或 `>=24.0.0`；release runner 使用 24.19.0 |
| DeepSeek Harness | 精确 `@deepseek-ai/dsh@0.1.0-rc.8` clean profile；Native/Code 九工具 Mock probe |
| MCP/Codex | stdio MCP、九项工具、离散 PNG/结构和共享语义动作；Codex 仍只是宿主之一 |
| Appium | external 默认；managed 显式 opt-in；文本用 W3C active element/rect/clear/value |
| Android | UiAutomator2 app-state/activate/terminate；可选 scrcpy 4.1 Viewer 媒体 |
| iOS | XCUITest/WDA app-state/activate/terminate 与固定 launchApp；可选 WDA MJPEG |

Mock、fake Appium、DSH/MCP runtime 与 Viewer E2E 是 release runner 可重复门禁。真实图像模型以及 Android/iOS 真机的普通文本和应用生命周期仍是单独外部验收层；没有对应授权、设备或凭据时不得报告为通过。

## 下载与校验

Release 只包含由精确 `v0.1.0-alpha.2` tag 的 clean runner 从单次 pack 产物生成的：

- `flowassert-0.1.0-alpha.2.tgz`
- `flowassert-0.1.0-alpha.2.sha256`
- `0.1.0-alpha.2.md`

```bash
shasum -a 256 --check flowassert-0.1.0-alpha.2.sha256
dsh plugin --profile web add ./flowassert-0.1.0-alpha.2.tgz
```

## 升级与回滚

不要覆盖个人配置。先从 alpha.2 CLI 生成新模板并与现有配置 diff，再显式选择策略。回滚时先 `mobile_mirror_stop`，移除当前宿主注册，并重新指向已经校验的 alpha.1 tarball；不要删除用户配置、attached session、系统 Appium/driver、证书、WDA 或设备信任状态。完整命令见 [Beta 安装与回滚指南](../beta-installation.md)。
