    MOCK · 复验与分享示意
    旧失败留下来，新结果单独看。
    先运行「失败流程」：实际点击一次，却期待两次。确认这个演示的期望设置错误后，修正为一次并复验。真实失败须先核查原因，不能直接把期望改成实际。
      尚无已完成记录。运行后在这里保留结果，刷新本页会清空模拟历史。
      运行与复验都仅在本页模拟，不保存产品运行记录。
      

      01 — START
      只检查本次需要的环境
      真实产品的 Mock 不要求手机或模型。真机先选择平台，检查连接前提，再显式连接。
      02 — REPEAT
      把一次操作保存为用例
      用 YAML 描述点击、输入、等待和断言。失败后查看历史材料，修改后产生新记录。
      03 — SHARE
      让同事也能读懂结果
      真实报告可审查图片、画框遮蔽后导出离线 HTML；是派生阅读材料，不是重新验收。
      

      这个演示与真实产品，有什么边界？
      • 默认 Mock 使用预设状态与人为延时，不连接设备、执行 AppClaw 或调用模型。历史仅在本页内存中，刷新清空；运行速度不是性能数据。
      • 成功案例参考 examples/flows/demo.yaml；失败案例把期望改为 2。模拟导出与产品报告的格式、真实性及持久化不同，不能导入工作台或当作真机证据。
      • 真实产品的通过要求声明的 UI 条件、必需证据及已配置的必选校验满足；未配置业务/视觉校验不代表这些维度通过。
      • 截至 2026-10-08，双端基础流程与部分故障恢复已有真机样本；广泛设备矩阵、真实外部业务、当前双宿主真实模型图片及独立用户验收仍待补齐。
      • 代码扩展与有限 AI 导航恢复已实现并有限定样本；证据驱动修复仍为 Preview，默认关闭。尚无公共 npm 安装。
